projects

  • cortex-vm — 64-bit VM and assembler in C. Word-addressed ISA, 64 registers, optional M and F extensions, round-tripping disassembler, ~400M instr/s at -O3.
  • forth — Forth 2012 Core interpreter. Switch-threaded bytecode VM on an arena, CREATE/DOES>, longjmp exception recovery. In progress.
  • marrow-lang — compiled language with a hand-written recursive-descent parser, targeting cortex-vm. In progress.
  • remem — memory recycler / GC for C. Size-classed arenas, O(1) page lookup.
  • arena — dependency-free arena allocator for C.
  • cpu-simulation — 8-bit CPU simulated in C and Python.
  • pure-quanta — quantum computer simulator in C over a complex state vector.
  • ml-in-c — ML primitives in C. In progress.
